# WarpTalk

## キャッチフレーズ
次元、時空を超えて「推し」と話そう！

## 概要
AIが忠実に推しになりきって会話してくれます。

## 使い方
友だち追加時に通知されます。

## 開発情報
- **開発期間**: 2024年12月～
- **開発人数**: 1人
- **サーバー**: GCP

## サービスのこだわり
1. 日常生活に溶け込んでいるLINE、そこに推しから通知が来ることでより身近に感じることが可能に！
2. 通知欄を見ると、推しの名前とアイコンが表示される！
3. 推しが沢山いる人も大丈夫！ひとりひとりと会話が可能！
4. 日付、曜日、時間も考慮して会話してくれます
5. AIが解釈不一致な回答をした場合でも自由に編集可能

## システムのこだわり
1. リアリティのある返答になるように設計
2. システム全体の柔軟性と拡張性を確保するため、依存関係逆転の原則を適用し、DB・メッセンジャーアプリ・AIなどを抽象化した上で、依存性注入を利用して実装を切り替え可能に設計
